# IT Home Lab

Hands-on notes from my structured Windows home lab. I work through a set of lab tasks each week, aimed at the everyday work of IT support and service desk roles, then write up what I did and what I learned.

Each week's notes include the commands I used, what I found in the lab, and the problems I fixed along the way.

## Weeks

| Week | Topic | What I practised |
|---|---|---|
| [Week 1](week-1-windows-foundations/README.md) | Windows Foundations | Local user management, `ipconfig`, `ping`, `tracert` and `nslookup`, Event Viewer (including Event ID 4625), services and startup apps, NTFS and share permissions |
| [Week 2](week-2-networking-basics/README.md) | Networking Basics | The TCP/IP model, IP addresses and subnet masks, DNS and DHCP, Wireshark captures of DNS, HTTP vs HTTPS and TLS |

## Lab setup

- **Lab machine:** win-lab01, a Windows 11 virtual machine in VMware Fusion on a Mac
- **Packet captures:** Wireshark, shown as labelled screenshots
- **How the notes are written:** only what I have worked through in the lab, written up at the end of each week
